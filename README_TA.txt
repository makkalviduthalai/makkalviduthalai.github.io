# கம்யூனிஸ்ட் கட்சி (மாலெ) மக்கள் விடுதலை — இணையதள தொடக்க வடிவம்

## இதில் உள்ளவை
- தமிழ் / English மொழி மாற்று
- மொபைல் மற்றும் கணினிக்கு ஏற்ற responsive வடிவமைப்பு
- அறிமுகம், கொள்கைகள், செயல்பாடுகள், எதிர்காலத் திட்டங்கள்
- செய்திகள், நிர்வாகக் குழு, உறுப்பினர் சேர்க்கை, நன்கொடை, தொடர்பு பகுதிகள்

## உங்கள் கணினியில் பார்க்க
1. ZIP-ஐ Extract செய்யவும்.
2. `index.html` கோப்பை Chrome / Edge-ல் திறக்கவும்.

## முக்கியமாக மாற்ற வேண்டியவை
`index.html`-ல் `[ ... ]` என்று உள்ள இடங்களில் அமைப்பின் அதிகாரப்பூர்வமாக ஒப்புதல் பெற்ற உள்ளடக்கங்களை இடவும்.
உண்மையான கொள்கைகள், நிர்வாகிகள், நிகழ்வுகள், தொடர்பு விவரங்கள் எதையும் இந்த மாதிரி தானாக உருவாக்கவில்லை.

## உறுப்பினர் விண்ணப்பம்
தற்போதைய படிவம் மாதிரி மட்டுமே; தரவைச் சேமிக்கவோ அனுப்பவோ செய்யாது.
வெளியிடுவதற்கு முன்:
1. Google Forms-ல் விண்ணப்பப் படிவம் உருவாக்கவும்.
2. தேவையான குறைந்தபட்சத் தகவல்களை மட்டுமே கேட்கவும்.
3. தனியுரிமை அறிவிப்பு, தரவை அணுகுபவர்கள், சேமிப்பு காலம் ஆகியவற்றைத் தெளிவுபடுத்தவும்.
4. `index.html`-ல் உள்ள மாதிரி படிவத்தை Google Form இணைப்புடன் மாற்றவும்.

## நன்கொடை
நன்கொடை இணைப்பைச் சேர்ப்பதற்கு முன் அமைப்பின் சட்டப்பூர்வ பதிவு, பொருந்தும் நிதி/வரி விதிகள், கணக்குப் பதிவு மற்றும் ரசீது நடைமுறைகளைச் சரிபார்க்கவும். தனிப்பட்ட வங்கிக் கணக்கு அல்லது சரிபார்க்கப்படாத payment link-ஐ பயன்படுத்த வேண்டாம்.

## இலவசமாக இணையத்தில் வெளியிடுதல் — GitHub Pages
1. GitHub கணக்கு உருவாக்கவும்.
2. புதிய Public repository உருவாக்கவும் (உதா: `makkal-viduthalai-site`).
3. இந்த ZIP-இன் உள்ளடக்கங்களை repository-க்கு upload செய்யவும். `index.html` repository root-ல் இருக்க வேண்டும்.
4. Repository → Settings → Pages செல்லவும்.
5. Build and deployment பகுதியில் `Deploy from a branch` தேர்ந்தெடுக்கவும்.
6. Branch `main`, folder `/ (root)` தேர்ந்தெடுத்து Save செய்யவும்.
7. சில நிமிடங்களில் GitHub இலவச முகவரியை வழங்கும்.

குறிப்பு: பொதுவான GitHub Pages தளத்தில் வெளியிடப்படும் தகவல்கள் அனைவருக்கும் தெரியும். தனிப்பட்ட உறுப்பினர் விவரங்கள் அல்லது உள்துறை ஆவணங்களை அங்கு வைக்க வேண்டாம்.
